# Clear Sans

Clear Sans Regular and Bold are bundled unchanged from Intel's official repository:

- https://github.com/intel/clear-sans
- https://github.com/intel/clear-sans/blob/main/TTF/ClearSans-Regular.ttf
- https://github.com/intel/clear-sans/blob/main/TTF/ClearSans-Bold.ttf

The repository distributes these fonts under Apache License 2.0; the original license is included in `LICENSE.txt`. Scythe embeds the files and loads a private application font collection. It does not install fonts globally or download them at runtime.

Original design credit from the upstream project: Daniel Ratighan at Monotype, under the direction of Intel's Open Source Technology Center user experience team. Typeface names and upstream attribution are retained.
